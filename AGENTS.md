# Development

Before adding or changing tests, read the shared test-audit authoring gate at
`$CODEX_HOME/skills/test-audit/SKILL.md`, then
`$CODEX_HOME/skills/contract-focused-tests/SKILL.md`.
Resolve `CODEX_HOME` to `~/.codex` when it is unset.

Library releases use `project.build.json`; see [NuGet publishing](Docs/NuGetPublishing.md).
PowerShell Gallery releases retain `Module/Build/Build-Module.ps1`.
